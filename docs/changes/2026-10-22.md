## Cover generation — the gauge-injection trap fired twice

Three attempts. Recorded because the failure mode is not obvious:

1. Prompt said *"no dials, no gauges, no charts, no numbers"* → image came back with a **clock/timer graphic overlaid in the top-right corner**.
2. Prompt said *"no clock, no watch face, no dial, no circular gauge, no timer"* → overlay gone, but the model **painted an analog wall clock into the gym**.
3. Prompt removed **every forbidden object word entirely** and changed the setting (empty stretching area, mat, bench; no window-heavy industrial gym) → clean.

**Rule: naming a forbidden object summons it, even inside a negation.** Describe only what IS in the frame. "No clock" is a worse instruction than describing an empty wall. This is the same class as the exit-cost post's gauge injection; the difference is that explicit negation makes it worse rather than better.
