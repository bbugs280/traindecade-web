# 2026-11-16 — traindecade: ZH posts linked to EN pages (8 posts, 15 links)

## The defect

Chinese-language posts linked to **English** pages. The link path was written as
`](/posts/<slug>/)` instead of `](/zh/posts/<slug>/)`.

A reader on a Chinese page who clicked such a link landed on `<html lang="en">` — a
published page in the wrong language. Not a 404 (EN posts live at root), so nothing
errored and no test caught it.

Verified live before the fix:

```
curl -s https://traindecade.com/posts/body-recomposition-men-over-40/ | grep 'html lang'
  → <html lang="en"
curl -s https://traindecade.com/zh/posts/body-recomposition-men-over-40/ | grep 'html lang'
  → <html lang="zh"
```

## Why it was invisible

- Not a 404: `/posts/<slug>/` is a real EN route, so all 15 links returned 200.
- The multilingual invariant test checks **hreflang pairing**, not link targets.
- ZH pages had 0 *outbound* ZH links, which read as "orphan" rather than "wrong-language".

It surfaced via the 2026-11-16 traindecade discovery cron, which reported
`pump-or-real-muscle` as "0 outbound links". That count came from a
`grep -o "](/zh/posts/"` pattern — the links existed but pointed at `/posts/`.
**The cron's number was wrong; the defect it pointed at was real and larger.**

## The fix

Mechanical rewrite of `](/posts/<slug>/)` → `](/zh/posts/<slug>/)` in `content-zh/posts/*.md`,
scoped to link syntax so body prose could not be touched.

Guard applied: **each target was checked for a ZH twin before rewriting.** A link whose
target had no ZH twin would have become a genuine 404, so those are left alone and reported.
Result: **0 skipped — every target has a ZH twin.**

Residual check after the run: `grep -l "](/posts/" content-zh/posts/*.md | wc -l` → **0**.

⚠️ **Note on grep and `--minify`:** the built HTML renders hrefs **unquoted**
(`href=/zh/posts/...`), so a quoted pattern like `href="/zh/posts/` returns zero on a
correctly-fixed page. Grep the bare slug and read context instead — a zero from a quoted
pattern is not evidence of a broken link.
