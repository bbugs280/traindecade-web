# 2026-11-22 — GainCut connector + studio network footer

## Why

A pipeline audit of the whole IdeaFactory portfolio found the marketing stage was not
*missing* — it was **unconnected**. Every property was an island:

```
traindecade.com   → zero links to ideafactory.one / builderdecade.com / Instagram
builderdecade.com → zero links to ideafactory.one / traindecade.com / Instagram
ideafactory.one   → zero links to either decade site, zero social
all sites         → ZERO email capture
4 Instagram accts → ZERO attributed sessions over 90 days
```

The measured consequence, per instrument:

| Instrument | Reading (before this change) |
|---|---|
| GSC 90d / traindecade | 20 clicks. Best page `/zh/posts/whey-vs-beef-protein/` — **8 clicks, 95 impr, pos 5.4** |
| GSC 90d / traindecade EN lane | position **52–97** on every query, 0 clicks |
| GA4 / ideafactory `/gaincut` | **2 sessions / 30 days** |
| App Store Connect | GainCut: **2 ratings** in ~4 months |

The Chinese lane is the only channel in the portfolio with proven demand, and its readers
already have exactly GainCut's intent (protein, body recomposition). There was no link
between the two. That is the gap this change closes.

## What changed

### 1. GainCut callout on every ZH post — `layouts/partials/gaincut_cta.html` (new)

Rendered from `extend_post_content.html`, gated on `site.Language.Lang == "zh"`.

- **45/45 ZH posts** now carry the callout — no per-file front-matter, so a future post
  cannot ship without it.
- **0 EN posts** carry it. Deliberate: the EN lane sits at position 52–97, so a product CTA
  there is untested noise on pages with no traffic.
- Per-slug attribution: `utm_campaign=zh-<slug>`, so GA4 credits the exact article that
  drove the click rather than lumping everything into one campaign.
- Carries `data-ga="gaincut_click"` + `data-ga-location`. ⚠️ The attribute alone is not
  proof it fires — the site's outbound-click listener must bind it. Verified in the test by
  asserting rendered output; the live click must still be confirmed once on the deployed site.
- Overridable per post with `hideGainCut: true` in front matter.

### 2. Studio network footer — both languages

Added to `layouts/partials/footer.html`:
```
Also from IdeaFactory: IdeaFactory · Builder Decade · Instagram
```
All three tagged `utm_source=traindecade&utm_medium=referral&utm_campaign=footer`.

New i18n keys: `also_from`, `gaincut_cta_title`, `gaincut_cta_body`, `gaincut_cta_button`
(zh.yaml also carries the CTA copy in Cantonese register, matching the vault's 粵語口語 rule).

## ⚠️ The stale-partial trap found while building

`builder-decade` has **two** footer partials:

```
layouts/partials/footer.html     ← stale duplicate, NOT rendered
layouts/_partials/footer.html    ← the one modern Hugo actually renders
```

The first edit went to the wrong copy. `hugo --quiet` exited **0** and the build silently
lacked the change. Only grepping the **rendered output** caught it.

**Rule: `hugo` exit 0 is not evidence a partial is live. Assert on rendered HTML.**

## Tests

New: `tests/test_gaincut_connector.py` — builds the site to a temp dir and asserts on
output, not source. Guards:
- every ZH post carries a tagged CTA (and the count is not zero)
- no EN post carries it
- footer network present and every link fully UTM-tagged

Existing suites still green:

```
test_multilingual.py        ✅ 45 EN / 45 ZH paired, hreflang bidirectional
check_no_stray_emphasis.py  ✅ 90 rendered posts
test_gaincut_connector.py   ✅ 45/45 ZH posts, 0 EN
```
