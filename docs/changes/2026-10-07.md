# 2026-10-07 — traindecade: AI-visibility pass — meta-description + duplicate-H1 sweep

## Context
AI-visibility audit of both decade sites (traindecade.com, builderdecade.com) at Vincent's
request. builderdecade came back clean (0 duplicate H1s, 1 description over). **traindecade
carried two display-layer defects that had never been swept** — the same two fixes that had
already shipped on its twin. These are the "page ranks, 0% CTR" defect family: the engine has
already judged the page relevant, but the SERP listing / heading signal is broken.

## Shipped

### 1. Meta descriptions — 45 over budget → 0
- **EN: 35 of 37 descriptions were over the ~155-char Google truncation limit** (median ~208,
  max 348 `somatic-awareness-body-feel`). Every English SERP snippet was cutting off mid-clause.
- **ZH: 10 of 37 over the ~78 full-width-unit budget** (max 103 `somatic-awareness-body-feel`).
- Rewrote all 45 to ≤155 chars (EN) / ≤78 fw-units (ZH), preserving each post's intent and hook,
  ending on a complete sentence. **Only the `description:` frontmatter line changed** — no title,
  body, tags, or date edits. No body prose touched.
- Verified on the **emitted** tags from the built output (quote-tolerant regex), not just source:
  `checked 74 pages, 0 bad`.

### 2. Duplicate `<h1>` — 16 pages (8 EN + 8 ZH) → 0
- PaperMod emits the frontmatter `title` as `<h1 class="post-title">`; these 8 post pairs *also*
  opened the body with a manual `# Heading`, rendering **two `<h1>`s with duplicate text**.
  Invisible in the repo and in a local diff — only present at render time.
- Deleted the redundant body `# Heading` line in both language twins. **The visible heading text is
  UNCHANGED** — the theme still renders the frontmatter title as the H1.
- 2 of 16 were `DIFF` cases (`somatic-awareness-body-feel`, EN + ZH): the body heading was a
  *prefix* of the frontmatter title, so the deleted line was the less-complete one — the frontmatter
  title (which carries the query terms) is retained.
- `lastmod` bumped to 2026-10-07 on all 16 files (both languages, so Google re-crawls both sides).
