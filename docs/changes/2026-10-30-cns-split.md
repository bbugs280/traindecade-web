## ⚠️ The ZH title changed a slogan into a search phrase — flag it

The old ZH title `你的肌肉沒問題。是你的神經系統累垮了。` was a **slogan**, not a
query string. The new one (中樞神經疲勞是什麼？症狀、恢復時間…) is a direct
translation of the intent. This is the riskiest single edit in the commit —
ZH is this site's only converting lane, and a title that reads as machine-translated
would hurt. Flagging for Vincent's read; revert is one line.
